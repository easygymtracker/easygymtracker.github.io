Privacy

A simple privacy posture: keep workout data on your own device.

This app is designed around local usage. Routines, sets, and session history are stored in the browser on the device you use, so you can manage training data without creating an account.

Home Features Open the app

What is stored

Routine definitions, set targets, exercise descriptions, and session history are saved in browser storage on your device.

What is not required

No user account, password, or remote profile is required to use the tracker.

Notifications

If you allow notifications, they are used for session-related reminders and workout flow while the app is running on your device.

Exports

When you export a routine, the resulting JSON file contains the routine structure and history data you chose to keep locally.

How it works

Build your routine

Add exercises with target reps, weights, and rest periods. Supports bilateral (two-handed) and unilateral (one-arm or one-leg) sets.

Start a session

Open a routine and start a session. Work through each exercise set by set, logging what you actually did.

Track your progress

After each session, rep and weight history is saved on your device. Review trends in the history charts for each exercise.

Stay in control

Export routines to a JSON file at any time. Import them back on the same or a different device without needing an account.
